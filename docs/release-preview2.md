# 第二预览版 · v0.5.3-preview.2

Windows 校园网托盘重连工具。配置网络和账号后，按设定周期检查连接，在支持的认证流程中尝试恢复网络。

## 下载

优先下载 **CampusReconnect-0.5.3-Single.exe**，双击运行，无需安装 Node 或手动解压。Windows 10/11 x64，需要 .NET Framework 4.8。

首次启动自动展开所需文件，后续复用并校验缓存；个人配置不包含在发行文件中。ZIP 提供相同 EXE、简要说明及许可，SHA256SUMS.txt 用于校验下载文件。

## 本预览提供

- 单文件启动，包含运行时、图标和网络辅助程序。
- 有线/无线渠道切换、手动重连与托管模式。
- 6/4/2 小时检测、唤醒后有限重试。
- 认证网址识别、一键配置、多账号与托盘后台运行。

## 验证与限制

首次展开、中文与空格路径、缓存复用、缓存损坏修复、主程序自检及全新用户初始状态检查通过。新用户没有预置账号或网关，自动连接与开机启动默认关闭。

这是第二次预览发布，应用内部版本为 0.5.3。不保证覆盖所有认证系统；验证码、扫码、多步认证需要手动处理。真实校园网认证、掉线和休眠恢复仍需具体环境验证。

升级前从托盘退出旧版，下载并运行新版。已有本机账号和配置会沿用。
