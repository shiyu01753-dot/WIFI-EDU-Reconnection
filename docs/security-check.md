# 本地检查记录

日期：2026-10-14。范围：0.5.0 当前源码与发行文件。检查不代替真实网络验证。

## 已检查

- 当前源码不含学校适配名单、预置账号密码、实际内网认证地址或预设 Wi-Fi 名称。个人配置不进入发行包。
- 账号密码使用当前 Windows 用户的 DPAPI 保存；请求网址、请求正文、凭据和原始响应不写入日志。
- 认证地址拒绝嵌入账号密码以及非 HTTP/HTTPS 协议。配置窗口规范化地址，认证编号只允许数字。
- 自动获取认证编号仅跟随同服务器跳转。表单提交拒绝跨服务器路径、查询参数和片段；不自动跟随提交后的跳转。
- HTTPS 保留系统证书验证，没有关闭验证的开关。
- 认证拒绝、未知引擎和无法确认成功的表单响应会暂停；正常联网和连接其他 Wi-Fi 时不会提交网页凭据。
- 系统网络恢复只调用 Windows 已保存的 Wi-Fi，不读取或提交网页密码。
- 三种调度间隔、网络配置映射、配置修改后的暂停、DPAPI、多账号、唤醒等待与重试上限已通过原生检查。
- 引擎测试使用合成凭据与文档地址；表单通信通过本机回环服务器测试，没有向实际学校提交账号密码。

## 边界

HTTP 认证可能暴露传输内容；本机密码加密不能保护未加密的网络传输。请使用网络提供方确认的地址，优先使用可验证的 HTTPS。

表单引擎仅支持简单 POST 和明确成功标记，不处理验证码、Cookie、CSRF、多步认证。错误的成功标记可能误判响应；即使收到成功标记，也仍检查外网恢复，无法确认时暂停。

配置文件位于本机用户目录，网络参数可编辑而非全部加密。当前 Windows 用户、本机管理员或有权限的恶意软件可能读取配置或运行时内存；DPAPI 不是对这类威胁的隔离保证。

本次检查针对当前文件与发行包。个人配置、日志、测试输出和本机授权资料不进入源码仓库。
