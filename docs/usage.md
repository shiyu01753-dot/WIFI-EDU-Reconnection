# 使用说明

## 配置窗口

连接校园网络后，主界面点击“一键配置”；或打开“网络配置”粘贴认证网址。程序读取页面并识别认证方式，填写认证地址、认证编号和当前 Wi-Fi 名称。界面不提供引擎选择。

检查识别结果后保存，配置名称与 Wi-Fi 名称映射回主界面，再填写账号密码并启用。发现过程不会读取已保存的密码，也不会提交认证或注销请求。

已联网且门户不再跳转时，可能无法发现认证页，需要粘贴认证网址。系统保存的企业 Wi-Fi 可识别为系统网络恢复。未知协议、验证码、CSRF 或多步认证不能保证自动配置成功，会提示用户处理。

发行包初始没有账号、密码、认证地址、认证编号或网络名称。网页引擎需自行填写网络参数；系统网络恢复只需要 Windows 已保存的 Wi-Fi 名称。

可以粘贴浏览器认证页面的完整网址。程序会去掉页面路径及查询参数，仅保存服务器地址，并尝试提取 `ac_id` 的数字。手动填写认证编号时优先使用该值；留空则自动获取。

识别到简单表单时，会提取提交路径、账号和密码字段名；仍需填写明确的成功标记，因为读取登录页不能证明登录后的响应。字段名不是账号密码。需要验证码、CSRF、Cookie 或多步认证的流程不能直接使用这一引擎。

修改网络配置会暂停自动检测。确定配置正确后点击“保存并启用”。账号密码在主界面编辑，支持多组保存、切换和默认账号。

## 运行

轻量模式 6 小时、待机模式 4 小时、夜间模式 2 小时检查。勾选“托管模式”后自动切换检测模式；取消勾选恢复手动选择。托管开关立即保存，自动检测仍由“保存并启用”或“暂停”控制。按小时检查不表示即时断网恢复。

主界面选择“有线”或“无线”，点击“保存并启用”后生效。有线时 Wi-Fi 名称不参与检测。配置发现、网络检查和认证请求绑定所选物理网卡的 IPv4 地址，不会自动切换到另一渠道。首次使用自动记录网卡与网关；连接变化时停止操作，确认新网络后重新保存。多个同类型网卡无法明确选择、缺少有效 IPv4/网关或特殊路由时会停止操作。网卡类型本身不能证明网络属于学校，应核对认证地址。

无线“断线重连”会断开并重新连接已保存的校园 Wi-Fi，再按需认证。有线模式下，支持注销的认证方式会核对当前账号后注销并重新认证；未提供安全注销方式的协议提示使用“立即检测”。不会禁用网卡或修改系统路由。有线完整认证流程仍需在实际校园网络验证。

唤醒后等待 20 秒检查，失败时每隔 60 秒重试，最多检查 3 次；认证被拒绝时暂停。暂停的应用不会因唤醒自行运行。

关闭窗口留在托盘，右键可立即检测、暂停、查看运行记录和退出。开机启动默认关闭，需主动勾选并保存。升级前先退出旧版，再运行新版。

## 数据与环境

配置位于 `%LOCALAPPDATA%\CampusReconnect`，密码由当前 Windows 用户 DPAPI 加密。网络参数以可编辑方式保存在本机，不能将个人配置上传到公开仓库。日志仅写通用状态，不记录请求网址或凭据。

适用于 Windows 10/11 x64，需 .NET Framework 4.8。运行包附带 Node.js；请完整保留 `runtime`、`licenses`、`reconnect.cjs`、`discovery.cjs`、`decrypt.ps1`、`campus.ico` 和 `CampusReconnect.exe.config`。

## 验证范围

引擎参数、模拟恢复、配置校验和本机表单通信已检查；真实网络恢复仍需实测。
