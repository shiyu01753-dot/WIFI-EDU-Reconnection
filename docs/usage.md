# 使用说明

## 启动

从 Releases 下载 `CampusReconnect-0.5.3-Single.exe`，双击即可。支持 Windows 10/11 x64，需要 .NET Framework 4.8；不需要另外安装 Node 或解压文件。

首次启动将运行所需文件展开到 `%LOCALAPPDATA%\CampusReconnect\app\版本-包哈希\`。后续启动校验并复用缓存，发现缺失或损坏时自动恢复。启动器完成启动后退出，后台只保留原托盘程序；认证引擎按需运行。

## 配置网络

主界面选择“有线”或“无线”，打开“网络配置”。点击“一键配置”，或粘贴浏览器中的认证网址，核对参数后保存。程序自动识别认证方式，界面不需要选择引擎。

发现过程不读取浏览器保存的密码，也不提交认证或注销请求。已联网而不再跳转认证页时，可能需要手动粘贴网址。无法识别或需要验证码、扫码、CSRF、Cookie 会话及多步认证时，需要手动处理。

保存网址时保留服务器地址，并尝试提取认证编号。简单表单可能识别出提交路径及账号、密码字段名，但登录成功标记仍需正确配置。修改网络参数会暂停自动检测，确认后重新点击“保存并启用”。

有线或无线检查绑定所选物理网卡的 IPv4 地址。首次保存会记录网卡与网关；连接变化、多个同类网卡无法明确选择或路由异常时停止操作。网卡类型本身不能证明网络属于学校，应核对认证地址。

## 账号与调度

填写自己的账号密码，支持多组保存、编辑、切换和设置默认账号。发行文件没有预置账号、认证地址、编号或 Wi-Fi 名称。

轻量、待机、夜间模式分别每 6、4、2 小时检查。勾选“托管模式”后按时段自动切换，取消勾选后恢复手动选择。自动检测由“保存并启用”或“暂停”控制，定时检查不表示即时掉线恢复。

休眠恢复后等待 20 秒检查，失败时每隔 60 秒重试，最多检查 3 次；认证被拒绝时暂停。已经暂停的应用不会因唤醒自行启用。

无线“断线重连”会断开并重新连接已保存的 Wi-Fi，再按需认证。有线模式下，仅在协议提供安全注销方式且能核对当前账号时注销并重新认证；其他情况提示使用“立即检测”。不会禁用网卡或修改系统路由。

## 后台与数据

关闭窗口后留在托盘，右键可检测、暂停、查看记录或退出。开机启动默认关闭，主动勾选并保存后才启用。升级前先从托盘退出旧版，再运行新版。

个人配置位于 `%LOCALAPPDATA%\CampusReconnect`，密码由当前 Windows 用户 DPAPI 加密。单文件版展开目录不是个人配置目录；启用开机启动时，快捷方式指向展开目录中的实际应用，请保留该目录。

## 源码构建

在 Windows PowerShell 中构建普通程序：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-app.ps1
```

普通构建需要自行准备运行时及辅助脚本。生成单文件发行版时，提供 Node x64 可执行文件和对应许可文件：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-single-file.ps1 `
  -NodePath "D:\Tools\node\node.exe" `
  -NodeLicensePath "D:\Tools\node\LICENSE"
```

输出位于 `dist/`，包含程序、脚本、图标、运行时和许可。脚本通过白名单收集文件，不打包 AppData 配置或账号。默认构建目录也位于 `dist/`，发布时选择生成的 EXE，不要上传构建中间文件。

测试入口：

```powershell
node .\tests\verify.cjs
node .\tests\discovery.cjs
node .\tests\manual-reconnect.cjs
node .\tests\channel.cjs
```

预览版已完成隔离启动、自检、展开缓存复用与损坏修复检查；真实校园网认证、掉线及休眠场景仍需实测。
