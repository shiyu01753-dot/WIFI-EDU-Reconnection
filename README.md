# WIFI-EDU-Reconnection

**校园网本地重连程序，专为校园网断连而生。**

在 Windows 托盘中运行，定时检查校园网连接，并在电脑从休眠恢复后额外检查。配置认证网址和账号后，程序会在支持的认证流程中尝试重新连接，减少手动打开网页登录的操作。

## 下载与使用

**[下载第二预览版 EXE](https://github.com/shiyu01753-dot/WIFI-EDU-Reconnection/releases/download/v0.5.3-preview.2/CampusReconnect-0.5.3-Single.exe)** · [版本说明与其他文件](https://github.com/shiyu01753-dot/WIFI-EDU-Reconnection/releases/tag/v0.5.3-preview.2)

适用于 Windows 10/11 x64，需要 .NET Framework 4.8。下载后双击运行，无需安装 Node 或手动解压。首次启动会自动展开所需文件，之后复用本地缓存。

1. 选择“有线”或“无线”，打开“网络配置”。
2. 点击“一键配置”，或粘贴认证网址，核对识别结果后保存。
3. 网页认证需要填写自己的账号密码；无线连接使用 Windows 已保存的 Wi-Fi 配置。
4. 点击“保存并启用”。关闭窗口后留在托盘，右键可检测、暂停或退出。

## 主要功能

- **自动配置**：发现当前网络与认证入口，填写能确认的参数；粘贴网址后自动识别处理方式。
- **定时检查**：轻量、待机、夜间模式分别每 6、4、2 小时检查，也可立即检测。
- **托管模式**：按时段自动切换检测模式，取消勾选后恢复手动选择。
- **唤醒恢复**：休眠恢复后等待网络就绪，再进行有限次数的检查。
- **有线与无线**：按保存的渠道检查和认证，无法确认网卡或连接时停止操作。
- **手动重连与多账号**：支持手动断线重连、保存多组账号、切换默认账号。
- **后台运行**：托盘驻留，认证引擎按需启动；开机启动默认关闭，可自行开启。

## 数据与限制

发行文件不包含账号密码、认证地址或个人配置。配置保存在 `%LOCALAPPDATA%\CampusReconnect`，密码由当前 Windows 用户 DPAPI 加密；已有配置会继续使用。

单文件版的运行文件位于 `%LOCALAPPDATA%\CampusReconnect\app\`，首次展开后会校验并复用。启用开机启动时，请保留该目录。

这是预览版本，并不保证支持所有校园网。验证码、扫码、多步认证和无法识别的流程需要手动处理。定时检查不等于即时掉线恢复；真实断网、休眠恢复及有线认证仍需在具体网络验证。
